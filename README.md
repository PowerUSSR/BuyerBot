# BuyerBot

NPC-бот "скупщик" для Paper/Spigot 1.20 на сервере **VortexiaPolit** — покупает у игроков предметы за игровую валюту, с автоматической ротацией страниц товаров каждые 4 часа.

## Команда

`/buyerbot [spawn|skin <ник>|page <1-3>|rotate|info]` — право `buyerbot.admin` (по умолчанию только ОП).

## Зависимости

- **Vault** (обязательно)
- **ProtocolLib** (обязательно)

## Сборка

```
build.bat
```
